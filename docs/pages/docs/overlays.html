Tabs

Use tabs to switch between related content within the same context.

Content for option 1.
Content for option 2.
<div class="tabs">
  <input type="radio" name="tabs" id="tab-1" checked />
  <label for="tab-1">Option 1</label>
  <section>Content for option 1.</section>

  <input type="radio" name="tabs" id="tab-2" />
  <label for="tab-2">Option 2</label>
  <section>Content for option 2.</section>
</div>
