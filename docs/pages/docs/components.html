Components

Buttons, cards, alerts, badges and tags — the building blocks for most interfaces.

Button

Button

A native <button> needs no class at all — add .btn to give a link or any other element the same look, then add one more class on top for a different finish. .btn-none goes the other way and removes the button styling entirely: 

<button>button</button>
<button class="btn">button</button>
<button class="btn-outline">.btn-outline</button>
<button class="btn-glow">.btn-glow</button>
<button class="soft">.soft</button>
<button class="ghost">.ghost</button>
<button class="phantom">.phantom</button>
<button class="surface">.surface</button>
<button class="surface-2">.surface-2</button>
<button class="accent">.accent</button>
<button class="btn-none">.btn-none</button>
.btn.soft 
<a class="btn soft" href="#">.btn.soft</a>

Add .disabled or aria-disabled="true" to mute any of them:

<button disabled>button</button>
<button class="btn" disabled>.btn</button>
<button class="btn-outline" aria-disabled="true">.btn-outline</button>
<button class="btn-glow" disabled>.btn-glow</button>
<button class="soft" disabled>.soft</button>
<button class="ghost" disabled>.ghost</button>
<button class="phantom" disabled>.phantom</button>
<button class="surface" disabled>.surface</button>
<button class="surface-2" disabled>.surface-2</button>
<button class="accent" disabled>.accent</button>
<button class="btn-none" disabled>.btn-none</button>

.btn-outline also reacts to its surroundings — inside (or combined with) an .accent surface it swaps to the on-accent color automatically, no extra class needed:

.btn-outline 
<div class="card accent">
  <a class="btn-outline" href="#">Button</a>
</div>
Card

Card

A flexible surface for grouping content together — headers, text, buttons, images, whatever the section needs.

Card title

Any content can go inside — text, buttons, images, forms.

<div class="card">
  <h2>Card title</h2>
  <p>Any content can go inside...</p>
</div>

Combine with any appearance modifier for a different finish:

.soft
.ghost
.phantom
.surface
.surface-2
.accent
<div class="card soft">...</div>
<div class="card ghost">...</div>
<div class="card phantom">...</div>
<div class="card surface">...</div>
<div class="card surface-2">...</div>
<div class="card accent">...</div>
Card Image

Card Image

Combining an image with content: stacked on top, or beside it on the left or right.

.card-img — image fills the top, content stacks below:

Stacked image

Content flows under the image, full width.

<div class="card-img">
  <img src="..." alt="" />
  <h2>Stacked image</h2>
  <p>Content flows under the image.</p>
</div>

.card-img-left:

Image on the left

Content sits to the right.

<div class="card-img-left">
  <img src="..." alt="" />
  <h2>Image on the left</h2>
  <p>Content sits to the right.</p>
</div>

.card-img-right:

Image on the right

Content sits to the left.

<div class="card-img-right">
  <img src="..." alt="" />
  <h2>Image on the right</h2>
  <p>Content sits to the left.</p>
</div>

Badge

Badge

A small label. Combine with .position-* to pin it onto a corner:

New 
<span class="badge">New</span>
12 
<div class="card">
  <span class="badge position-tr">12</span>
</div>

There are a few badge variations, for a different look:

.soft .ghost .phantom .surface .surface-2 .accent

<span class="badge surface">...</span>
