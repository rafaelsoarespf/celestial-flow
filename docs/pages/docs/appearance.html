Appearance

Modifiers

Modifiers

Classes that override background, border, and text color at once — combine one with almost any component (.btn, .card, .badge, .tag...) to change its finish, instead of needing a dedicated variant class for every combination.

.surface

Default layer — solid theme background, blurred.

<div class="card surface">...</div>

.surface-2

Nested layer, sits visually on top of .surface.

<div class="card surface-2">...</div>

.ghost

Outline only — no background, no blur.

<div class="card ghost">...</div>

.phantom

Blur only — no background tint, for glass over busy content.

<div class="card phantom">...</div>

.soft

Accent-tinted background, accent-colored text.

<div class="card soft">...</div>

.accent

Solid accent block, text automatically flips to on-accent.

<div class="card accent">...</div>
