Documentation

Installation

Celestial Flow has zero dependencies and no build step required. Link the stylesheets, link the script, and you're ready to build.

Prerequisites

Before you start

Celestial Flow is plain CSS and vanilla JavaScript — no Node, no package manager, no build tools. You only need a code editor and a way to serve static files (a live-reload extension, or any static host).

Step 1

Add the framework to your project

Place the celestial-flow folder — containing css, fonts, and js — inside your project. Your structure should look like this: 

your-project/
├── celestial-flow/
│   ├── css/
│   │   ├── reset.css
│   │   ├── globals.css
│   │   ├── themes.css
│   │   ├── fonts.css
│   │   ├── typography.css
│   │   ├── layout.css
│   │   ├── spacing.css
│   │   ├── appearance.css
│   │   ├── decorative.css
│   │   ├── components.css
│   │   ├── forms.css
│   │   ├── overlays.css
│   │   ├── structure.css
│   │   └── animations.css
│   ├── fonts/
│   │   ├── sora/
│   │   └── plus-jakarta-sans/
│   └── js/
│       └── celestial-flow.js
└── index.html
Step 2

Link the stylesheets and script

Add everything to your <head>. Stylesheets must follow this order — reset.css first, animations.css last, the rest following the cascade from base to component-level styles. The script uses defer so it doesn't block page rendering; it powers the theme selector, navbar, sidebar, panels, and the select component. 

<head>
  <!-- reset -->
  <link rel="stylesheet" href="celestial-flow/css/reset.css">

  <!-- base: tokens, themes, fonts -->
  <link rel="stylesheet" href="celestial-flow/css/globals.css">
  <link rel="stylesheet" href="celestial-flow/css/themes.css">
  <link rel="stylesheet" href="celestial-flow/css/fonts.css">
  <link rel="stylesheet" href="celestial-flow/css/typography.css">

  <!-- utilities -->
  <link rel="stylesheet" href="celestial-flow/css/layout.css">
  <link rel="stylesheet" href="celestial-flow/css/spacing.css">
  <link rel="stylesheet" href="celestial-flow/css/appearance.css">
  <link rel="stylesheet" href="celestial-flow/css/decorative.css">

  <!-- components -->
  <link rel="stylesheet" href="celestial-flow/css/components.css">
  <link rel="stylesheet" href="celestial-flow/css/forms.css">
  <link rel="stylesheet" href="celestial-flow/css/overlays.css">
  <link rel="stylesheet" href="celestial-flow/css/structure.css">

  <!-- animations -->
  <link rel="stylesheet" href="celestial-flow/css/animations.css">

  <!-- script -->
  <script src="celestial-flow/js/celestial-flow.js" defer></script>
</head>
Step 3

Set a theme

Add a data-theme attribute to your <html> tag to set the default theme. See the Themes page for the full list.

<html data-theme="dark">
