Themes

Celestial Flow is theme-first — every color, font, shadow, and radius is a CSS variable, and switching themes is a single attribute.

How it works

One attribute, one file

Each theme is a [data-theme="..."] selector in themes.css that defines a fixed set of CSS variables — colors, fonts, letter spacing, shadows, radii, and blur. Every component in the framework is built entirely from these variables, so setting the attribute on <html> restyles the whole page instantly, with no JavaScript required. 

<html data-theme="dark">

Variables

What a theme controls

Every theme defines the same set of variables. Overriding all of them is what makes a theme — components never hardcode a color, font, or radius.

Color

--color-background Page background
--color-surface-1 Cards, panels
--color-surface-2 Nested surfaces
--color-border Borders and dividers
--color-accent Primary brand color
--color-on-accent Text/icons on accent
--color-title h1 color
--color-subtitle h2 color
--color-heading h3–h6 color
--color-text Body text color

Typography, Shape & Depth

--font-title-hero Hero heading shorthand
--font-title h1 shorthand
--font-subtitle h2 shorthand
--font-heading-3..6 h3–h6 shorthand
--font-text-lg / -text / -text-sm Body text sizes
--letter-spacing-* Per-level tracking
--shadow-sm / -md / -lg Elevation scale
--radius-sm / -md / -lg Corner radius scale
--blur Backdrop blur amount
Custom Themes

Build your own

Add a new [data-theme="..."] block to themes.css (or your own stylesheet, linked after it) with the same variable set. Every component picks it up automatically — nothing else needs to change.

[data-theme="sunset"] {
  --color-background: linear-gradient(135deg, #2b1055, #7597de);
  --color-surface-1: rgba(255, 255, 255, 0.06);
  --color-surface-2: rgba(255, 255, 255, 0.1);

  --color-border: rgba(255, 180, 120, 0.2);
  --color-accent: #ff7b54;
  --color-on-accent: #1a0e05;

  --color-title: #fff5ee;
  --color-subtitle: #f2d9c9;
  --color-heading: #e0bfa9;
  --color-text: #c9a893;

  --letter-spacing-title-hero: -0.02em;
  --letter-spacing-title: -0.01em;
  --letter-spacing-subtitle: 0;
  --letter-spacing-heading: 0;
  --letter-spacing-text: 0;

  --font-title-hero: 700 clamp(2.75rem, 3.5rem + 3vw, 5.5rem) "Sora", sans-serif;
  --font-title: 700 clamp(1.75rem, 1.4rem + 1.5vw, 2.25rem) "Sora", sans-serif;
  --font-subtitle: 600 clamp(1.375rem, 1.2rem + 0.7vw, 1.75rem) "Plus Jakarta Sans", sans-serif;
  --font-heading-3: 600 clamp(1.25rem, 1.15rem + 0.4vw, 1.5rem) "Plus Jakarta Sans", sans-serif;
  --font-heading-4: 600 clamp(1.125rem, 1.05rem + 0.3vw, 1.25rem) "Plus Jakarta Sans", sans-serif;
  --font-heading-5: 600 clamp(1.0625rem, 1rem + 0.25vw, 1.125rem) "Plus Jakarta Sans", sans-serif;
  --font-heading-6: 600 1rem "Plus Jakarta Sans", sans-serif;
  --font-text-lg: 400 1.25rem "Plus Jakarta Sans", sans-serif;
  --font-text: 400 1rem "Plus Jakarta Sans", sans-serif;
  --font-text-sm: 400 0.875rem "Plus Jakarta Sans", sans-serif;

  --shadow-sm: 0 2px 6px rgba(0, 0, 0, 0.2);
  --shadow-md: 0 8px 20px rgba(0, 0, 0, 0.3);
  --shadow-lg: 0 18px 40px rgba(0, 0, 0, 0.4);

  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 20px;

  --blur: blur(16px);
}
