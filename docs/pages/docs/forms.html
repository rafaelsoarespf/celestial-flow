Documentation

Forms

Build clear and accessible forms with consistent styling and behavior.

Input

Input

An <input> is styled by default:

Enabled:

<input type="text" />

Disabled:

<input type="text" disabled />
Textarea

Textarea

Use a textarea to let users enter multiple lines of text.

Enabled:

<textarea placeholder="Text"></textarea>

Disabled:

<textarea placeholder="Text" disabled></textarea>
Field

Field

Use a field to display a floating label that moves above the input when focused or filled. The input requires a placeholder attribute, which can be a single space.

<div class="field">
  <input type="text" id="full-name" placeholder=" " />
  <label for="full-name">Full name</label>
</div>
Checkbox

Checkbox

Use checkboxes to let users select one or more options.

<label><input type="checkbox" /> Unchecked</label>
<label><input type="checkbox" checked /> Checked</label>
<label><input type="checkbox" disabled /> Disabled</label>
Radio

Radio

Use radio buttons when users need to select one option from a group.

<label><input type="radio" name="option" checked /> Option A</label>
<label><input type="radio" name="option" /> Option B</label>
<label><input type="radio" name="option" /> Option C</label>

Disabled:

<label><input type="radio" name="option" disabled /> Option A</label>
Switch

Switch

Use .switch on a checkbox input to display it as an on/off toggle:

<label class="row gap-sm center-items"><input type="checkbox" class="switch" /><span>Off</span></label>
<label class="row gap-sm center-items"><input type="checkbox" class="switch" checked /><span>On</span></label>
<label class="row gap-sm center-items"><input type="checkbox" class="switch" disabled /><span>Disabled</span></label>
Range

Range

Use a range slider to select a value from a defined range.

<input type="range" min="0" max="100" value="40" />
File

File

Use a file input to let users select a file from their device.

<input type="file" />
Color

Color

Use a color input to let users select a color.

<input type="color" value="#7c9cff" />
Progress

Progress

Use a progress bar to indicate the completion of a task. Omit the value attribute for an indeterminate progress state.

<progress value="60" max="100"></progress>
<progress></progress>
Input Group

Input Group

Group related inputs, labels, or buttons into a single connected control:

https:// 
<div class="input-group">
  <span>https://</span>
  <input type="text" placeholder="yourdomain.com" />
  <button type="button">Go</button>
</div>
Select

Select

Use a select to let users choose one option from a list.

Standard

<select>
  <option>Option 1</option>
  <option>Option 2</option>
</select>

Custom

<div class="select">
  <button class="select__btn" type="button">Choose an option</button>
  <div class="select__menu">
    <button class="select__item" type="button" data-value="option-1">Option 1</button>
    <button class="select__item" type="button" data-value="option-2" data-selected>Option 2</button>
  </div>
</div>
