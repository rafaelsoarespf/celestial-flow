Containers, sections, a percentage-based grid, and alignment utilities to structure any page.

Container

Container

Caps content width at 1200px and centers it. Nearly every section in this framework wraps its content in one.

.container1200px 
<div class="container">
  ...
</div>

Combine with a .width-N class to center a narrower box — .container supplies the centering, .width-N caps the size below 1200px.

.container. + .width-400 400px 
<div class="container width-400">
  ...
</div>

Grid

Grid

A 12-column, percentage-based grid. Wrap columns in .grid, then size each child with .col-1 through .col-12. Below 480px, every column stacks full-width automatically.

.col-4
.col-4
.col-4
<div class="grid">
  <div class="col-4">...</div>
  <div class="col-4">...</div>
  <div class="col-4">...</div>
</div>

Columns don't need to be equal:

.col-4
.col-8

Leave off .col-N and children split evenly on their own — useful when you don't want to calculate a fraction for every item:

1
2
3
4
5

Mixing is fine too — items with .col-N take a fixed share, items without it split whatever space remains:

.col-3
no class — fills the rest

.col-6 50% .col-12 100%

Alignment

Alignment

Five directions — center, top, right, bottom, left — each with three variants that follow the same pattern:

.center

Centers the element itself and its children.

.center-items

Centers the children only.

.center-self

Centers the element itself only.
