## Why Celestial Flow

Most frameworks give you building blocks and leave the visual identity to you. Celestial Flow does the opposite: **the theme comes first**. Every surface, color, border and effect is built to follow the active theme, so interfaces look cohesive from the first line of markup, and restyling an entire page never means rewriting it.

- **Theme-first.** Switching the whole look of a page is a single attribute.
- **Quick to start.** Link the framework and start building, with no configuration needed.
- **Markup-first.** Components and effects are applied with classes and attributes, right in your HTML.
- **Cohesive by default.** Everything shares one design foundation, so combining pieces never looks patchwork.
- **Easy to extend.** Your own styles can build on or override the framework without a fight.

## At a glance

Link the framework, pick a theme, and build with classes and attributes:

```html
<html data-theme="theme-name">
```

Change the value of `data-theme` and every component, surface and effect on the page follows.

## Getting started

1. **Add the framework** to your project by copying the `celestial-flow` folder.
2. **Link the stylesheets and the script** in your `<head>`, following the order in the Installation guide.
3. **Choose a theme** on the `<html>` element with `data-theme`.
